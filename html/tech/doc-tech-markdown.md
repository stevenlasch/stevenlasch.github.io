### Tech: Markdown

#### Markdown: Log Entries

- 2024-12-02: If you write all your documents in Markdown and set them as plain text, you can always reset them as markdown to stand out
- 2024-11-01: Follow this document for the layout standard. H1 for the title of the document. 
    - Each section starts with H2 and Table of contents after the H1
    -  Use dividers before every H2

#### Markdown: Standards
- Keep the notes small. Topics should be easily consumed.

#### Benefits of writing Markdown
- You can paste markdown into Jira comments and it will display as preview
- You can attach a .md file in Teams and it will show a link that will display the content as preview
- Standardized documentation
- Benefits the consumer more
